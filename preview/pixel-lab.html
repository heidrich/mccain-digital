Same words, same size, same engine. Only the grid differs. Hover each one — the black hole works, so you can see how a setting behaves in motion, not just at rest.

A is the old setting, B the one that was too dense, C the default now. Note that A and B measure identically: the engine rounds both numbers to whole device pixels and keeps the block below the cell, so several requests collapse onto the same grid. That rounding is the fix — A used to render as a fractional block at a fractional position, which is what made it pale.
