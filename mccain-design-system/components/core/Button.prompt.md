Pill-Button für alle CTAs – Primär in Navy mit Chevron (auf Dunkel Himmel), Ghost als Hairline, Dark in Navy.

```jsx
<Button chevron onClick={openContact}>Projekt anfragen</Button>
<Button variant="ghost">Die Seite fragen</Button>
<Button variant="ghost" onDark>llms.txt</Button>
```

Höhen 40/44/48; Hover hebt −1 px, Navy wird #1A3A6E (auf Dunkel Himmel wird #77CCFF); kein Shrink beim Drücken. `pixel` aktiviert den Pixel-Zerfall aus `assets/pixel-engine.js`.
